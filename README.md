# UPVM Café

## Descripción

UPVM Café es un proyecto desarrollado para la materia **Desarrollo de Aplicaciones Móviles** de la **Universidad Politécnica del Valle de México (UPVM)**.

El proyecto tiene como finalidad desarrollar una solución digital para la cafetería de la universidad, permitiendo a estudiantes y personal consultar los productos disponibles, seleccionar alimentos y bebidas y realizar pedidos de manera más organizada.

La versión actual corresponde a la **base inicial del proyecto**, con una interfaz web que presenta el menú de la cafetería y un formulario para recopilar información del pedido.

## Objetivo

Desarrollar una aplicación para la cafetería de la UPVM que permita consultar el menú, seleccionar productos y gestionar pedidos de manera sencilla, reduciendo tiempos de espera y facilitando el proceso de compra.

## Funciones principales

* Consultar el menú de la cafetería.
* Visualizar productos y precios.
* Consultar productos organizados por categorías.
* Seleccionar información relacionada con un pedido.
* Registrar datos básicos del cliente.
* Indicar si el pedido será para recoger o entregar.
* Agregar productos y cantidades al pedido.
* Especificar peticiones especiales.

> Las funciones de generación de número de pedido, procesamiento completo del pedido y consulta de estado se encuentran contempladas dentro del objetivo del proyecto y serán desarrolladas en etapas posteriores.

## Estructura del proyecto

La estructura actual del proyecto contiene un archivo HTML principal, una hoja de estilos y recursos gráficos utilizados por la interfaz.

```text
UPVM CAFE/
├── index.html
├── styles.css
├── *.jpg
├── *.png
└── README.md
```

### Archivos principales

**`index.html`**

Contiene la estructura principal de la interfaz de UPVM Café, incluyendo:

* Página principal.
* Sección de objetivo.
* Categorías del menú.
* Lista de productos y precios.
* Formulario de pedido.
* Secciones visuales de confirmación y preparación.

**`styles.css`**

Contiene los estilos visuales utilizados para diseñar y presentar la interfaz del proyecto.

**Archivos `.jpg` y `.png`**

Son recursos gráficos utilizados en la interfaz, incluyendo imágenes de productos, ilustraciones, categorías y elementos visuales de la aplicación.

**`README.md`**

Contiene la documentación general del proyecto, sus integrantes, tecnologías, estructura, instalación y estado de desarrollo.

## Instalación y ejecución

La versión actual del proyecto corresponde a una interfaz basada en HTML y CSS, por lo que no requiere actualmente la instalación de dependencias mediante `npm`.

Para ejecutar la versión actual:

1. Descargar o clonar el repositorio.
2. Abrir la carpeta `UPVM CAFE`.
3. Abrir el archivo `index.html` en un navegador web.

### Ejecución desde Visual Studio Code

También puede abrirse el proyecto desde Visual Studio Code y visualizar `index.html` utilizando una herramienta de servidor local compatible con el proyecto.

> Cuando la implementación de React Native sea integrada al proyecto, esta sección deberá actualizarse con los comandos de instalación y ejecución correspondientes a la configuración real del proyecto.
